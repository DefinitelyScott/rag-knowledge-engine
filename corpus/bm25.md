# Okapi BM25

BM25 is the ranking function that most production keyword search still runs on.
It scores a document against a query by adding up a contribution for each query
term that appears in the document. Three ideas shape that contribution.

The first is inverse document frequency. A term that occurs in almost every
document tells you very little about which document to return, so its weight is
pushed toward zero. A rare term is highly discriminative and gets a large
weight. BM25 uses a smoothed form of IDF, log(1 + (N - df + 0.5) / (df + 0.5)),
where N is the number of documents and df is the number containing the term.

The second is term frequency saturation. If a word appears twenty times instead
of ten, the document is not twice as relevant. BM25 passes the raw count
through tf * (k1 + 1) / (tf + k1 * ...), a curve that rises quickly for the
first few occurrences and then flattens. The parameter k1, usually set between
1.2 and 2.0, controls how quickly saturation sets in. Setting k1 to zero
reduces the model to a pure binary presence test.

The third is length normalisation. A long document has more chances to contain
any given term, so without correction long documents would dominate. BM25
divides by a factor that grows with the ratio of document length to the average
document length in the collection, scaled by the parameter b. With b = 1 the
normalisation is full, with b = 0 it is switched off entirely. The common
default is b = 0.75, which normalises partially.

BM25 is fast, needs no training data, and is remarkably hard to beat on queries
that share vocabulary with the target document. Its weakness is vocabulary
mismatch: a query asking about "cars" scores zero against a document that only
ever says "automobiles". That is the gap dense retrieval and query expansion
try to close, and the reason hybrid retrieval exists.

The formulation used here follows Robertson and Zaragoza, "The Probabilistic
Relevance Framework: BM25 and Beyond" (2009), which traces BM25 back to the
probabilistic relevance model of Robertson and Sparck Jones.
